How to run

  1. Run database_implementation.sql, then routines.sql.
  2. Run routines_example_usage.sql. It starts a transaction, makes each call, and rolls back, so the sample data is left as it was and you can run it again.
  3. Calls that are refused (a SIGNAL) would stop a script, so those are left to project2/tests/test_routines.py.
