find queries (Task 3)

F1Catalogue search box ac

A listener types part of a name; match track titles or artist stage names, case-insensitive.

db.tracks.find(
  { $or: [ { title: { $regex: "static", $options: "i" } },
           { "artist.stage_name": { $regex: "static", $options: "i" } } ] },
  { _id: 1, title: 1, "artist.stage_name": 1 })

Expected: 4817, 4818 (artist Velvet Static), 4821 (Cathedral Static).

F2Station candidates under the station's model bcd

Stations want tracks that genuinely sit between genres under the model the station uses. Return only that model's score.

db.tracks.find(
  { scores: { $elemMatch: { "model.version_label": "beardown_rrm",
                            posterior_entropy: { $gte: 0.6 } } } },
  { title: 1, "scores.$": 1 })

Expected: 4825, 4826, each with its beardown_rrm score only.

F3Jazz–hip-hop crossovers bc

For the “Late Jazz Hop” station: any score in which hip-hop carries real weight. $elemMatch nested two levels, so genre and probability must hold in the same element.

db.tracks.find(
  { scores: { $elemMatch: { probabilities: { $elemMatch: {
      "genre.name": "hiphop", probability: { $gte: 0.30 } } } } } },
  { title: 1, "artist.stage_name": 1 })

Expected: 4817 (hip-hop 0.3426 under beardown).

F4Payout console c

Finance pays verified artists by country; list their tracks and the payout rate on the embedded artist.

db.tracks.find(
  { "artist.verified": true, "artist.country": { $in: ["GB", "DE"] } },
  { _id: 0, title: 1, "artist.stage_name": 1, "artist.payout_rate": 1 })

Expected: 4819, 4820 (Mara Quell, GB), 4827, 4828 (Juno Fleet, DE).

F5Featured shelf ce

The home page only features tracks that are scored and come from verified artists.

db.tracks.find(
  { $nor: [ { ingest_status: "rejected" },
            { ingest_status: "awaiting scoring" },
            { "artist.verified": false } ] },
  { title: 1, "artist.stage_name": 1 })

Expected: 10 tracks (all but Tin Harbour's 4823, 4824 and Saltmarsh Tapes' 4829–4831).

F6Scoring backlog

Operations watches for uploads that no model has scored yet.

db.tracks.find({ scores: { $size: 0 } }, { title: 1, ingest_status: 1 })

Expected: 4830 (awaiting scoring), 4831 (rejected).

Aggregation pipelines (Task 4)

A1Compare BEARDOWN versions ab

Which classifier version leaves tracks most ambiguous, and how confident is it on average?

db.tracks.aggregate([
  { $unwind: "$scores" },
  { $group: { _id: "$scores.model.version_label",
              tracks: { $sum: 1 },
              mean_entropy: { $avg: "$scores.posterior_entropy" },
              mean_top_probability: { $avg: "$scores.top_probability" },
              holdout_accuracy: { $first: "$scores.model.holdout_accuracy" } } },
  { $sort: { mean_entropy: -1 } }])

Expected: 4 models. Model 3 (beardown_rrm_cfg17) scored nothing, so it cannot appear: a limit of this boundary worth saying in the comment.

A2Genre shelves ac

Browse shelves: under the production model, which tracks sit on each top genre?

db.tracks.aggregate([
  { $unwind: "$scores" },
  { $match: { "scores.model.version_label": "beardown_rrm" } },
  { $group: { _id: "$scores.top_genre.name", tracks: { $push: "$title" } } },
  { $sort: { _id: 1 } }])

Expected: 8 shelves holding 10 tracks.

A3Genre fingerprint chips d

The track page shows, per model, only the genres with at least 10% probability.

db.tracks.aggregate([
  { $match: { ingest_status: "scored" } },
  { $project: { title: 1, fingerprint: { $map: { input: "$scores", as: "s", in: {
      model: "$$s.model.version_label",
      genres: { $filter: { input: "$$s.probabilities", as: "p",
                           cond: { $gte: ["$$p.probability", 0.10] } } } } } } } }])

Expected: 13 tracks.

A4Artist-facing track card e

The artist dashboard wants a flat card, not the stored document.

db.tracks.aggregate([
  { $match: { ingest_status: "scored" } },
  { $project: { _id: 0, artist: "$artist.stage_name", track: "$title",
                minutes: { $round: [{ $divide: ["$duration", 60] }, 2] },
                models_scored: { $size: "$scores" },
                released: { $dateToString: { format: "%Y-%m", date: "$release_date" } } } }])

Expected: 13 cards.

A5Review queue: models disagree ab

Tracks whose models name different top genres go to a human for review before retraining.

db.tracks.aggregate([
  { $unwind: "$scores" },
  { $group: { _id: "$_id", title: { $first: "$title" },
              top_genres: { $addToSet: "$scores.top_genre.name" },
              max_divergence: { $max: "$scores.model_divergence" } } },
  { $match: { "top_genres.1": { $exists: true } } }])

Expected: 4818 (jazz/blues), 4821 (metal/classical), 4828 (pop/disco).

A6Most between-genre artists abe

Editorial picks artists whose catalogue sits furthest between genres.

db.tracks.aggregate([
  { $unwind: "$scores" },
  { $group: { _id: "$artist.artist_id", artist: { $first: "$artist.stage_name" },
              mean_entropy: { $avg: "$scores.posterior_entropy" },
              tracks: { $addToSet: "$title" } } },
  { $project: { _id: 0, artist: 1, mean_entropy: 1, track_count: { $size: "$tracks" } } },
  { $sort: { mean_entropy: -1 } }])

Expected: 7 artists.
